## About

I build **business software with PHP and Laravel** — the systems companies actually run on: CRM platforms, HR management tools, admin dashboards, and the REST APIs that connect them to web and mobile clients.

My approach is straightforward: understand the business process first, model the data properly, then write code the next developer can pick up without a handover meeting. I care more about systems that stay maintainable after a year than about clever shortcuts that look good on day one.

Currently **open to remote roles and freelance projects**.

## How I Work

**1 · Understand** — I start with the business process and the actual users, not the tech. Requirements get written down and confirmed before any code.

**2 · Design** — Database schema and application structure planned up front, so features don't fight the architecture later.

**3 · Build** — Work delivered in reviewable pieces, not one big drop at the end. You see progress as it happens.

**4 · Deliver & Support** — Deployment, walkthrough, and support after launch. The handover includes clean source code, not a black box.
